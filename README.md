# Real Time Sign Language Detection

## Description:

Developed a deep learning-based system to detect and interpret sign language gestures in real time using LSTM neural networks and action recognition. Implemented using Python, TensorFlow, and OpenCV, the system captures hand gestures via webcam, processes video frames, and classifies them into corresponding signs. Integrated with Zoom to enable live sign-to-text translation, enhancing communication for the hearing impaired.

## Duration: 
Feb 2024 - Apr 2024

## Tech Stack:

Machine Learning / Deep Learning TensorFlow (v2.0.0) – For training and deploying the LSTM-based sign recognition model LSTM (Long Short-Term Memory) – Deep learning architecture for temporal gesture analysis

Computer Vision OpenCV (v3.4.2) – For real-time video capture, image processing, and hand landmark tracking Mediapipe (by Google) – For efficient hand keypoint detection and tracking

Development Tools Python (v3.7.4) – Core programming language Jupyter Notebook – Development and experimentation environment Anaconda – Package and environment manager

Annotation & Labeling LabelImg – Tool for labeling hand gestures with bounding boxes for dataset creation

Libraries & Dependencies NumPy (v1.16.5) – For numerical operations and data manipulation cv2 – OpenCV Python bindings
